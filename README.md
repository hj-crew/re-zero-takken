# 🏰 Re:ゼロから始める宅建RPG

ようこそ、国家資格がモンスターと化す世界へ。

このアプリは、**React + Vite + Tailwind CSS** で構築された異世界宅建クイズRPGです。  
プレイヤーはミニマップを移動しながら、突如襲いかかる宅建モンスター（問題）と戦います。  
正解すれば経験値を獲得し、不正解ならHPを削られる──それがこの世界の掟。

---

## ✨ 特徴

- ⬆⬇⬅➡キーで探索できるミニマップ
- ランダムエンカウントで宅建クイズバトル
- 正解でEXP獲得＆レベルアップ
- 不正解でHPが減る本格RPG風仕様
- Tailwindで整えた爽やかUI
- Vercelデプロイ対応（予定）
